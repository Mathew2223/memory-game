# Memory Game

## Description

A classic memory card matching game built with vanilla JavaScript. The objective is to find all 8 matching pairs of cards in the fewest moves possible. The project features smooth 3D flip animations, a move counter, and a persistent local leaderboard.

## Features

- **3D Card Animations:** Smooth and visually appealing card flip effects using CSS 3D transforms.
- **Game Logic:** Tracks moves, matched pairs, and prevents invalid clicks (e.g., clicking during the preview or on already matched cards).
- **Local Leaderboard:** Saves the top 10 best results (number of moves and date) using the browser's `localStorage`.
- **Responsive Design:** Fully adapts to different screen sizes, ensuring a great experience on both desktop and mobile devices.
- **Modular Architecture:** Clean code structure using modern ES6 JavaScript modules.

## Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, 3D Transforms, Animations)
- Vanilla JavaScript (ES6+)
